# Readable Specification Workflow — E2E Scenario

Источник истины для ручной проверки по `specs/001-redesign-spec-workflow/quickstart.md`.
Проверяется plugin package release **0.27.0**; binary OMP проверяется независимо
(например, `omp/18.0.11`) и не обязан совпадать с версией пакета. Исполнять на
реальном OMP PTY через `@andvl1/omp-workflows-e2e`, не через mock runtime.

## Правила

- Перед каждым validation action перечитывать этот файл. Выполненные `[x]` не
  повторять; идти с первого `[ ]`.
- Сначала сохранять evidence в указанном точном tracked пути, затем менять `[ ]`
  на `[x]`. При ошибке оставить `[ ]` и сохранить failure evidence.
- Scratch допускается в `/tmp/omp-ux-e2e-readable-spec-workflow/`, но до отметки
  каждого пункта все transcript/document/hash/claim/matrix/screenshot нужно
  скопировать в tracked `vibe-report/runtime/readable-spec-workflow/`.
- Для PTY использовать только `npm run e2e -- …`; останавливать сеансы только
  этой командой с явно указанным scratch-путём. Не применять `kill`, `pkill`,
  `killall` или обход harness. Screenshots реального UI получать через
  `playwright-cli`. Все пункты ниже изначально не выполнены.
