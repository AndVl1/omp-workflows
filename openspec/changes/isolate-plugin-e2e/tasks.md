- [x] 3.3 Реализовать `api-key-env`, внешний `broker`, явный `native-host-broker` и provider-free `none`; native broker env interface, приватный run cache и секреты без argv/manifest. `native-host-broker` использует выбранную OpenAI Codex/xAI OAuth авторизацию установленного omp по profile fingerprint, один подтверждённо принадлежащий менеджеру процесс на профиль, безопасный native token file и отказ от чужого listener; cleanup run не останавливает broker, только отдельная адресная команда. Проверка: конкурентные broker clients не создают второго менеджера; неподтверждённое межпроцессное single-flight не отмечено verified.
  - Статус приёмки: startup/reuse и конкурирующие manager clients проверены на отдельном fixture-профиле; обновление OAuth grant с независимыми обычными omp-клиентами не проверялось — отдельные контролируемые credentials для refresh-эксперимента отсутствуют. Рабочий токен не вращать ради теста.
